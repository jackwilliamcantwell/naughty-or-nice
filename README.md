# Naughty or Nice

The Friendmas game app. Live at https://jackwilliamcantwell.github.io/naughty-or-nice/

- Data is stored in Firebase Firestore (project naughty-or-nice-beb92), under `games/friendmas-2026`.
- `firestore.rules` holds the database rules to paste into the Firebase console. They switch the database off after 31 January 2027.
- Everyone opens the game with their personal link (listed in the CFO control room under Links & setup).
